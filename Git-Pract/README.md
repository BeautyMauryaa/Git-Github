# Git & GitHub Practice

Learning Git and GitHub from fundamentals to real-world workflows.

```text
before:
Working Directory
       │
       └── README.md
             ↓
          UNTRACKED


after:
Working Directory
       │
       ↓
   git add README.md
       │
       ↓
Staging Area
       │
       └── README.md
```

# complete flow:

```text
                 YOU CREATE FILE
                       │
                       ↓
              Working Directory
                       │
                    git add
                       ↓
                Staging Area
                       │
                  git commit
                       ↓
               Local Repository
```
