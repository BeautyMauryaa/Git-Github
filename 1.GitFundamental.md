# 1.1 What is Git?

- distributed version control system , maintaining a history of project
- it tracks changes, compare changes, go back to previous versions, work on features seperately, combines developers work, identify when bugs were introduced, collaborate safely

# 1.2 Repository & .git:

- Pract is a project that git is tracking assume:

pract -> index.html ,style.css,app.js,.git/

- .git directory is what makes this git repo

- 1. git init -> creates .git
- actual project + .git -> git repo

- .git-> it contains the git's internal information including the repo's history and metadata

  # 1.3 Working Directory:
  - it is basically the files you are currently working on.
  - ex: index.html, style.css app.js these are wokring files

  # 1.4 Staging Area:
  - preparing changes for the next commit
  - ex: modified three files and only want to commit two

- git add index.html
- git add style.css
- now index.html and style.css is staged

# 1.8 git add

- moves changes into staging area
- specific file: git add index.html
- multiple files: git add index.html style.css
- everything: git add .
- means: stage the current version of this changes for the next commit

  # 1.9 git commit
  - git commit -m "Add button"
  - commit records the staged changes
  - working directory -> git add -> staging area -> git commit -> git history

    # 1.10 git log / git show:
    - to see commits
    - git log/ git log --oneline(cleaner output)

    - git show: want to inspect a specific commit, show what that commit changed
    - git show <comit-hash>

    # 1.11 git diff:
    - shows the diff btw the committed version and our current unstaged changes
