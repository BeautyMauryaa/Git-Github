```text 
Command	Main job
git init	-> Create a local Git repository
git remote add	-> Connect local repo to a remote
git add	-> Put changes into staging
git commit	-> Record staged changes locally
git push	-> Send local commits to remote
git fetch	-> Download remote updates/information
git pull	-> Fetch + integrate remote changes
```
