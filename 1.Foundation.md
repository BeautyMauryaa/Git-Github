# Version Control:
- A system that tracks changes made to files, projects, or repositories over time.
- Allows you to track changes, see previous versions, identify who made changes, compare changes, restore previous versions, collaborate with other developers, and maintain a complete history of the project.

# Git:
- A Distributed Version Control System (DVCS).
- **Breakdown of 'Distributed':** Every developer working with a Git repository has a complete copy of the repository and its entire history locally on their machine.

# GitHub:
- A cloud-based platform used for hosting Git repositories and collaborating on software projects.

```text
Git ──> Is a Distributed Version Control System
GitHub ──> Is a hosting Platform built around Git
```

# Repository (Repo):
- The digital directory or folder where Git stores the project's files and all of its version-control history metadata (`.git` folder).
- **Two types of repositories:**
  1. **Local:** Stored directly on your personal computer/PC.
  2. **Remote:** Hosted on the cloud or somewhere else, most commonly on GitHub.

```text
YOUR COMPUTER                 GITHUB

my-project/                   my-project/
     │                             │
     │                             │
 Local Git Repo              Remote Git Repo
```

- they can communicate through such command:

```text
git push 
git pull
git fetch
```
