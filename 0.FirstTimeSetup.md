# 1.Git setup and tell who you are:

- 0.1 Git installed?
- 0.2 Git identity/config
- 0.3 GitHub account setup
- 0.4 SSH authentication
- 0.5 Verify everything

```
1. git --version
2. git config --global user.name "Beauty"
3. git config --global user.email "your-email@example.com"
4. git config --global init.defaultBranch main (optional)
5. git config --global --list


```

## --global means:

- use this identity for git repo on this system by default
- so we don't have to configure our name and email every time when we create a repo

# 2.Configure the default branch

- modern github repo commonly use "main"
- but mainly we have two default branch main and master
- we can tell git which branch to use

```
git config --global init.defaultBranch main

```

# 3. GitHub Account:

- now we move from Git -> GitHub
- github account gives access to
- repo,pull request, issues, github actions, collaboration, code hosting

# 4. SSH Authentication:

- git push -> when we runs this github needs to answer -> who is this user and are they allowed to push?
- so SSH lets user authenticate to Github without repeatedly entering credentials.

### Basic architecture:

Your Computer
│
│ SSH
↓
GitHub
│
↓
"Is this public key associated with this account?"
│
↓
YES ✅

- will have key pair -> private key(stay only on your system never upload it to github or send it to anyone) + public key
- to check : ls ~/.ssh
- to create if don't have: ssh -T git@github.com
